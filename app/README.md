# MMM · 음음음 2.6.0

하루를 한 마디 소리로 남기는 **Java Swing 데스크톱 앱**입니다. 실제 연주·편집·저장·재생이 동작하며 인터넷 없이 사용할 수 있습니다. 발표 자료는 보존하고 `app/` 안에서 구현했습니다.

## 2.5 원격 모드

`../devserver/start.cmd`로 개발 서버를 시작하고 **remote.cmd**로 클라이언트를 실행합니다. 두 창에서 각자 가입한 뒤 공동 곡 초대·저장·새로고침을 확인할 수 있습니다. 일반 원격 서버는 Spring Boot와 PostgreSQL을 별도 실행하고 `--server=HTTPS주소` 또는 `MMM_SERVER_URL`로 연결합니다. [서버 실행·API·호환 안내](../REMOTE.md)를 확인하세요.

클라이언트 기본/악기 323개와 실제 Swing 218개, 서버 HTTP(S)/DB 시나리오 24개가 통과했습니다. 기타 입력 회귀 검사 81개와 실시간 그림·누른 길이·저장·MIDI 검사 37개를 포함합니다. 전체 빌드는 저장소 루트의 `build-m2.ps1 -GuiTests`입니다. 이 아래 기존 2.4 배포 링크는 로컬 모드 기준입니다.

## 악기별 연주 화면

피아노는 건반, 베이스는 4줄, 기타는 6줄과 코드/노트, 드럼은 킥·스네어·하이햇·탐·심벌 키트를 보여줍니다. **음 편집**은 기존 소리 그림 편집으로 전환하고 **새로 연주**는 확인 후 입력을 비웁니다. 개발 미리보기에서 **F5**로 새 코드를 반영하세요. [조작과 소리 안내](docs/INSTRUMENT-SURFACES.md)를 확인하세요.

기본 **누른 길이대로** 모드는 누르는 동안 소리 그림이 자라고 떼면 길이를 확정합니다. **연주 설정**에서 단계 입력·4박 녹음과 연주 세기를 고를 수 있습니다. [실시간 소리 그림](docs/LIVE-SOUND.md)을 확인하세요.

## Windows 실행

Java 21 이상이 필요합니다. **`demo.cmd`를 더블클릭**하면 2026-11-16 시연 모드가 열립니다. 시작 화면의 **샘플 바로 듣기** 또는 `demo / demo1234`로 들어갑니다. **`run.cmd`는 일반 모드**이며 직접 가입한 계정을 사용합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -GuiTests
.\demo.cmd
```

첫 명령은 기본 검사 182개와 JAR 생성을 수행합니다. 두 번째는 표시 가능한 데스크톱에서 Swing 검사 127개를 추가합니다. 실행 파일은 `build/MMM.jar`, 증거는 `build/evidence/`입니다. `JAVA_HOME`이 없으면 PATH의 javac가 사용하는 JDK를 찾습니다.

소스 없이 사용할 때는 [MMM-2.4-local.jar](../downloads/MMM-2.4-local.jar) 또는 [Windows 묶음](../downloads/MMM-2.4-local-windows.zip)을 사용합니다. 빌드 도구인 JDK는 소스 빌드 때 필요하고, 실행은 Java 21 이상 런타임이면 됩니다.

## v0.2 표현 기능 사용

1. 오늘 편집에서 음을 선택하고 **표현 ··· → 짧게 끊기**를 선택합니다. 음의 논리 길이와 다음 음 시작은 유지되고 실제 소리만 절반 길이로 끊깁니다. **보통 음으로** 되돌릴 수 있습니다.
2. **점점 세게**에서 시작·끝 위치(0~4박), 시작·끝 세기를 지정합니다. 구간에 들어오는 음의 시작 위치에 따라 두께와 MIDI 세기가 함께 달라집니다. 겹친 표현 구간은 거부하며 **크레센도 지우기**로 초기화합니다.
3. **쉼으로**는 선택 음의 시간과 길이를 갖는 명시적 쉼으로 변환합니다. 다른 음이 가로지르면 거부합니다. **쉼 1박**은 입력 위치에 쉼을 추가합니다.
4. 캔버스 아래쪽의 쉼 띠를 선택해 좌우·꼬리 드래그, 길이 슬라이더, 좌우 방향키로 조절합니다. Delete/Backspace는 쉼을 제거해 빈칸으로 돌립니다. 쉼만 있는 마디도 저장됩니다.
5. 메모는 선택 사항입니다. 공백 포함 최대 20 코드포인트를 입력하고 저장하면 음·쉼·표현·메모가 재실행 후 복원됩니다. 로컬 schema 1/2는 그대로 읽고 다음 쓰기 때 곡 버전을 포함한 schema 3과 이전 정상 파일 백업을 남깁니다. 원격 음악 기록은 schemaVersion 2를 사용합니다.

최소 창은 1000×720입니다. 작은 창에서는 선택 속성을 세로로 스크롤할 수 있으며 표현 메뉴·건반·정지·저장은 접근 가능합니다. Pretendard Regular/Bold와 SIL OFL 라이선스를 JAR에 포함합니다. [개발 내역·검증 한계·M2 남은 범위](docs/DEVELOPMENT-v0.2.md)를 확인하세요.

## 2.5.4 피아노 건반과 음역 이동

흰/검은 건반이 2개·3개씩 놓이는 피아노를 제공합니다. 양옆 **‹ ›** 버튼이나 건반 포커스의 **← →**로 한 옥타브씩 이동하며 **MIDI 0–127(C-1–G9)** 전체 음역을 클릭·드래그로 연주합니다. **Home**은 기본 C3–C6으로 돌아갑니다. 흰 건반 **A S D F G H J K**, 검은 건반 **W E T Y U**도 현재 음역에 따라 바뀝니다. 5음계 모드에서는 도·레·미·솔·라만 활성화합니다. [디자인과 조작 안내](docs/PIANO-DESIGN.md)를 참고하세요. 확장 음역의 원격 저장은 서버도 2.5.4로 업데이트해야 합니다.

## GitHub에서 받은 경우

이 저장소에는 개인 기록, 계정 파일, JDK 설치본, macOS 앱 묶음이 포함되지 않습니다. **Java 21 이상 JDK**를 설치하고 `JAVA_HOME`을 지정한 뒤 아래 명령으로 빌드합니다. macOS 앱은 `./package-mac.sh`로 생성합니다.

```sh
git clone https://github.com/suimay/MMM.git
cd MMM/app
./build.sh
./demo.command
```

바로 실행할 JAR는 [MMM-2.4-local.jar](../downloads/MMM-2.4-local.jar)에 있습니다. Java 21 이상에서 `java -jar MMM-2.4-local.jar --demo-date=2026-11-16`로 실행하세요. 시연 계정은 공개 샘플 계정이며 실제 인증 정보가 아닙니다.

## 로컬 앱 실행

Mac용 `.app`은 `./package-mac.sh`로 별도 생성합니다. 이번 Windows 개발에서는 macOS 패키징을 실행하지 않았습니다. 기존 `dist/MMM.app`이 있다면 이전 버전일 수 있습니다. `demo.command`는 **2026-11-01 기준 시연 모드**로 열립니다.

```sh
cd MMM/app
./demo.command      # 같은 고정 날짜 시연 모드
./run.command       # 실제 서울 날짜, 샘플 없는 일반 로컬 모드
./build.sh          # Java 21 컴파일 + 기본 182개/건반 33개/전체 음역 11개 검사
./test-gui.sh       # 실제 데스크톱에서 Swing 통합 검사 135개
./package-mac.sh    # 런타임 포함 dist/MMM.app 생성 (이전 앱 묶음은 별도 이름으로 보관)
```

`build/MMM.jar`는 Java 21 이상에서 `java -jar MMM.jar`로 실행합니다. Maven/Gradle 없이 JDK 기본 도구만 사용하는 프로젝트입니다. 시스템 Java 대신 `tools/`의 Temurin 21.0.13+9를 사용할 수 있고, 다른 JDK는 `JAVA_HOME`으로 지정합니다. 다른 운영체제에서 JAR 실행은 가능하도록 작성했지만 실제 검증은 이 Mac에서 수행했습니다.

## 2.3에서 다듬은 흐름

- **S01 프롤로그**: m 세 글자를 눌러 듣고 슬라이더로 높이→음높이, 너비→길이를 바꿉니다. 첫 화면은 글자 체험에 집중하고 건반·악기 선택은 편집 화면에 둡니다. 편집기는 도레미파솔라시도가 기본이며 5음계도 선택할 수 있습니다.
- **S07 통합 감상**: 소리 덩어리를 클릭하면 우측에 도/C4·시작 박·길이·세기가 뜹니다. 메모도 같은 화면에 있고 전체 음 목록은 필요할 때 펼칩니다. 친구 기록은 선택·듣기만 가능하고 드래그로 수정되지 않습니다.
- **S05 개인 주간**: 요일 ▶는 그날부터 일요일까지 이어 듣기, 반복도 선택한 요일부터입니다. 아래 기록 열기/오늘 편집은 별도 버튼입니다.
- **S08/S09 공동**: 요일 버튼 또는 S08 표 머리글로 그날 모든 참여자의 합주를 바로 듣습니다. 날짜 칸은 친구 기록을 확인하는 동작입니다. 참여자별 한 주 재생·개별 음 감상·실시간 음소거·음량과 기존 반복/정지/위치 조절을 유지합니다.
- **S14 소리 일기장**: 날짜별 소리 그림·메모·작성자·악기를 모아 봅니다. 검색·기간·작성자·메모 유무·정렬 필터, 선택 기록 듣기/열기, 필터 결과 메모 TXT 내보내기를 제공합니다.
- 최소 창에서 통합 상세는 세로 스크롤로 소리·속성 영역을 보존합니다. 4종 악기/3종 아바타 PNG는 로컬 ImageIcon으로 표시합니다.
- [14화면·5대화상자 컴포넌트/이벤트 표](docs/components.md), [실행 캡처 ZIP](docs/presentation-captures.zip), [사용자 행동→이벤트→피드백과 UX 검토](docs/UX-REVIEW.md)를 제공합니다. 컴포넌트와 배치/모델/그리기 API를 구분합니다.

## 들어 있는 샘플

개인곡 **나의 작은 일주일**, **노을 산책**, 공동곡 **우리의 느린 오후**, **주말의 작은 합주**에 시연 기준일 포함 최근 **14일**의 샘플을 채웁니다. 새 공동 샘플은 `demo`의 멜로디, `star`의 베이스, `moon`의 드럼으로 구성합니다. 멜로디는 C 펜타토닉을 기본으로 하며 기존에 저장된 샘플은 유지합니다.

- 최초 새 데이터에는 개인 28개 + 공동 84개, 총 112개 한 마디가 생성됩니다.
- 기존 곡 이름·설정과 **이미 저장된 음·메모·버전은 덮어쓰지 않습니다**. 비어 있는 샘플 기록만 채웁니다.
- 같은 기준일에서 반복 실행해도 샘플이 중복되거나 수정 기록이 초기화되지 않습니다.
- 일반 모드에는 샘플 계정·기록이 생기지 않습니다. 공동 계정과 원격 협업 서버를 혼동하지 않도록 화면에 로컬/시연 표시가 있습니다.

## 일기 중심 화면과 소리 덩어리

2.1에서는 기존 제안서의 의미 있는 소리 덩어리를 복원했습니다. **꼬리 길이 = 음 길이, 몸통 두께 = 세기, 위아래 = 높낮이**, 가로 위치는 시작 시각입니다. 균일한 원통/캡슐이 아닙니다. 선택은 주황 윤곽과 꼬리 손잡이, 재생 중은 주황 채움, 읽기 전용은 회색으로 구분합니다. 꼬리 끝을 드래그하면 음 길이가 바뀝니다.

연주 설정·곡 관리·내보내기는 관련 메뉴로 묶고, 편집 화면에서는 건반·덩어리·메모·하루 저장에 집중합니다. 보관함·주간 날짜에도 같은 덩어리의 썸네일이 보입니다. 상세 기준은 [디자인 가이드](docs/DESIGN.md)에 있습니다.

## 실제 앱처럼 사용하는 흐름

1. **샘플 바로 듣기 → 곡 선택 → 주간 재생**으로 한 주를 들어봅니다.
2. 각 요일의 ▶는 이어 듣기입니다. 아래 **오늘 편집**은 S06, **기록 열기**는 과거 S07 감상, 미래는 잠금입니다. 오늘도 별도 ‘저장본 감상’으로 읽기 전용 확인이 가능합니다.
3. S06의 건반을 클릭하고 `A S D F G H J K`로 연주합니다. 샘플이 이미 4박을 채웠다면 **다시 연주**로 비운 뒤 입력하거나 기존 음을 편집하세요.
4. 소리 덩어리를 드래그하거나 선택 후 방향키로 이동하고, 오른쪽에서 길이·높낮이·세기를 조절합니다. **Delete/Backspace**로 선택 음을 지웁니다. 오른쪽 ‘표현’ 메뉴에는 쉼·짧게 끊기·점점 세게가 있습니다.
5. **편집 전 듣기 → 들어보기**로 차이를 비교합니다. ‘편집 전’은 첫 시각 편집 직전 음의 복사본이며 악기·BPM은 현재 값을 사용합니다.
6. 메모 → **하루 저장 → D03 확인**. 주간이 저장소에서 다시 읽히고 재실행해도 복원됩니다.

건반·재생·저장 버튼은 기본 창에서 항상 보입니다. 선택한 덩어리의 속성만 오른쪽에 나타나고 추가 표현은 메뉴로 엽니다. 메뉴와 저장 상태, 선택 음의 높이·길이·세기, 메모 글자 수가 표시됩니다.

| 조작 | 단축키 |
|---|---|
| 저장 | Cmd/Ctrl+S |
| 실행 취소 / 다시 실행 | Cmd/Ctrl+Z / Shift+Cmd/Ctrl+Z |
| 새 곡 / 보관함 / 설정 | Cmd/Ctrl+N / O / 쉼표 |
| 건반에서 미리 듣기·정지 | Space |
| 모든 소리 정지 | Escape |
| 도움말 | F1 |

실행 취소/다시 실행에는 음·쉼·표현 구간·메모·악기·BPM·입력 위치가 포함됩니다. 한 번의 음 드래그/슬라이더 조작은 한 단계로 묶입니다. 키보드 단축키의 Cmd/Ctrl 조합은 건반 소리를 내지 않습니다.

## 입력·재생·합주

- 단계 입력은 시간 제한 없이 1박씩 입력합니다. ‘쉼 1박’은 명시적인 쉼을 추가하고 입력 위치를 옮깁니다.
- 실시간 입력은 선택한 1~8박 카운트인 뒤 4박 동안 녹음합니다. 설정에서 메트로놈 소리를 켤 수 있습니다. `System.nanoTime()`으로 캡처하고 1/4박에 맞추며 마디 끝에서 자릅니다.
- 4/4, PPQ 480, 1920tick 한 마디, 최소 120tick. 음높이 MIDI 0~127, 음 겹침 허용, 한 마디 최대 128개 음, 메모 20 코드포인트.
- **재생 막대**: 재생·일시정지·계속 재생·정지·반복·위치 이동. S05/S06/S07/S09에서 동일한 조작을 사용합니다.
- **S09 합주**: 날짜 또는 해당 주 전체 7마디 선택. ‘내 소리만 / 친구 소리만 / 모두 선택’과 파트별 체크·음량으로 비교합니다. 파트 음소거/음량 변경은 재생 중 MIDI 채널에 즉시 반영합니다.
- 공동곡은 공통 BPM으로 재생·편집합니다. 주간 재생도 곡 BPM 하나를 사용합니다. 날짜별 개인 BPM 변화는 개별 S07 감상에서 적용됩니다.
- 빈 날짜/파트는 쉼입니다. 정지·화면 이동·창 포커스 상실 시 음을 종료하며, 반복 keyPressed는 중복음을 만들지 않습니다.

## 곡 관리·악보·파일

- **S10**: 곡 이름·BPM·기본 악기 변경, 참여자·권한 목록. 소유자만 변경 가능하고 저장 전 취소는 데이터에 영향을 주지 않습니다. 오래된 설정으로 덮어쓰는 충돌도 거부합니다.
- **D02**: 공동곡 소유자가 발급한 코드로 같은 저장소의 계정을 초대합니다. 코드 복사, 7일 만료, 무효/만료/중복 참여 구분. 시연의 시계는 고정이므로 시연에서 시간이 자연히 흐르지는 않습니다.
- 참여자는 공동곡에서 탈퇴할 수 있습니다. 과거 기여 기록은 남고 접근 권한만 사라집니다. 소유자 탈퇴·소유권 이전·곡 삭제는 지원하지 않습니다. 합주는 최대 15파트입니다.
- **S11**: 내 주간 NoteEvent를 시간 비례 오선보로 표시, 75~150% 확대, 페이지 분할 인쇄. macOS 인쇄창의 PDF 저장도 사용할 수 있습니다.
- **악보 범위**: 4·2·1·1/2·1/4박 음표·쉼표, 스타카토 점과 크레센도를 표시합니다. 합성 길이는 일반 음표로 추정하지 않고 사각 표식·수치·시간선으로 보완합니다. 명시적 쉼과 미입력 빈칸을 구분합니다. 전문 조판 수준의 성부 분리·음표 충돌 회피·연음/붙임줄·기보 철자 선택은 하지 않습니다. 조밀한 화음은 표기가 겹칠 수 있습니다.
- **MIDI 내보내기**: S06의 ‘더 보기’, S07/S09/S11에서 현재 음, 한 주 또는 선택한 합주를 `.mid`로 저장합니다. BPM·4/4 박자·악기·파트 음량을 포함하며 전체 청취 음량은 파일에 굽지 않습니다. 원본 기록은 바뀌지 않습니다.

## 날짜와 데이터 보호

일반 모드는 기기 시계의 **Asia/Seoul 오늘**, 시연 모드는 명시한 고정 날짜입니다. 서버 날짜라고 주장하지 않습니다.

- 일반: `~/.mmm/local/mmm.properties`
- 시연: `~/.mmm/demo-2026-11-01/mmm.properties`
- 위치 변경: `./run.command --data=/원하는/폴더` 또는 시연 옵션 `--demo-date=YYYY-MM-DD`.
- 파일 잠금·전체 형식 검사·버전 확인·임시 파일 flush·원자 교체로 저장합니다. 쓰기 전 정상 파일은 `mmm.properties.bak`에 이전 상태로 백업합니다. 최초 새 파일에는 이전 백업이 없습니다.
- 손상 파일을 자동 초기화하거나 덮어쓰지 않습니다. 앱을 모두 닫고 별도 원본 사본을 보관한 뒤 정상 백업으로 복원하거나 새 `--data` 위치를 선택하세요. 자동 복구 UI는 없습니다.
- D04는 저장하고 이동 / 버리고 이동 / 계속 편집. 닫기·취소는 편집 유지입니다.
- D05 저장 실패 시 초안 유지 후 재시도. 버전 충돌이나 자정 경계에서 이전 날짜 저장을 강제로 허용하지 않습니다. 충돌 초안 병합과 영구 초안 자동저장은 지원하지 않습니다.
- 계정 비밀번호는 PBKDF2 해시로 저장하지만 **로컬 데모 인증**입니다. 실제 서비스 비밀번호를 사용하지 마세요.
- 저장소 형식이 확장됐으므로 이전 버전 창은 닫고 새 앱을 사용하세요. 기존 데이터는 새 앱에서 읽어 유지합니다.

## 구현 범위와 구조

S01~S14와 D01~D05를 구현했습니다. S14 일기장은 선택 기능입니다. 화면 ID는 내부 식별자입니다. **2.5는 Spring Boot·PostgreSQL·HTTP 세션·원격 공동 기록·서버 권한/날짜 검증을 제공합니다.** 점수·랭킹·업적은 추가하지 않았습니다. M2 검증 한계는 [검증 기록](docs/M2-VERIFICATION.md)에 명시했습니다.

- `Model`: 그래픽·소리·저장의 공통 immutable NoteEvent, RestEvent, ExpressionRange, Phrase.
- `MusicService`: 로그인·권한·날짜·곡 관리. `Repository` 계약 / `LocalRepository` 파일 어댑터로 분리.
- `MMM`: 단일 JFrame/CardLayout, 화면·대화상자·SwingWorker.
- `EditorPanel` / `Piano` / `NoteCanvas`: 입력·UndoManager·편집·Graphics2D.
- `MidiEngine` / `Transport`: MIDI, 일시정지·반복·위치 이동·내보내기.
- `ProloguePanel` / `PersonalWeekPanel` / `SharedWeekPanel` / `EnsemblePanel`: 체험·요일 재생·공동 기록·합주.
- `RecordInspector` / `JournalPanel`: 통합 감상과 소리 일기장·검색·메모 내보내기.
- `ScorePanel`: 동일 모델의 악보 렌더링·Printable 페이지 분할.
- 수업 요소: KeyListener, MouseListener, MouseMotionListener, ActionListener, ChangeListener와 Border/Flow/Grid/Box/CardLayout, Swing 폼·목록·표·슬라이더·스피너·탭·대화상자.

기존 앱 조작 방식은 [Apple GarageBand 공식 사용 설명서](https://support.apple.com/en-gb/guide/garageband/welcome/mac)의 피아노롤 편집·실행 취소/다시 실행·메트로놈 흐름을 참고했습니다. MMM에 맞게 단순화했으며 GarageBand 호환성이나 동일한 기능 전체를 주장하지 않습니다.

검증 결과와 실제 화면은 `docs/VERIFICATION.md`, `docs/S06-editor.png`, `docs/S09-ensemble.png`, `docs/S10-management.png`, `docs/S11-score.png`에 있습니다. 자동 검사는 별도 임시 데이터만 사용합니다.

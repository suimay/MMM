# MMM · 음음음 2.3

하루를 한 마디 소리로 남기는 **Java Swing 데스크톱 앱**입니다. 실제 연주·편집·저장·재생이 동작하며 인터넷 없이 사용할 수 있습니다. 발표 자료는 보존하고 `app/` 안에서 구현했습니다.

## GitHub에서 받은 경우

이 저장소에는 개인 기록, 계정 파일, JDK 설치본, macOS 앱 묶음이 포함되지 않습니다. **Java 21 이상 JDK**를 설치하고 `JAVA_HOME`을 지정한 뒤 아래 명령으로 빌드합니다. macOS 앱은 `./package-mac.sh`로 생성합니다.

```sh
git clone https://github.com/suimay/MMM.git
cd MMM/app
./build.sh
./demo.command
```

바로 실행할 JAR는 [MMM-2.3.jar](../downloads/MMM-2.3.jar)에 있습니다. Java 21 이상에서 `java -jar MMM-2.3.jar --demo-date=2026-11-01`로 실행하세요. 시연 계정은 공개 샘플 계정이며 실제 인증 정보가 아닙니다.

## 로컬 앱 실행

**Mac에서는 `dist/MMM.app`을 더블클릭**하세요. Java 런타임이 포함되어 있어 별도 Java 설치 없이 실행됩니다. 이 패키지는 Apple Silicon용이며 **2026-11-01 기준 시연 모드**로 열립니다. 시작 화면의 **샘플 바로 듣기**를 누르면 보관함에 들어갑니다. 수동 로그인은 `demo / demo1234`입니다.

```sh
cd MMM/app
./demo.command      # 같은 고정 날짜 시연 모드
./run.command       # 실제 서울 날짜, 샘플 없는 일반 로컬 모드
./build.sh          # Java 21 컴파일 + 101개 모델/기능 검사 + build/MMM.jar
./test-gui.sh       # 실제 데스크톱에서 Swing 통합 검사 75개
./package-mac.sh    # 런타임 포함 dist/MMM.app 생성 (이전 앱 묶음은 별도 이름으로 보관)
```

`build/MMM.jar`는 Java 21 이상에서 `java -jar MMM.jar`로 실행합니다. Maven/Gradle 없이 JDK 기본 도구만 사용하는 프로젝트입니다. 시스템 Java 대신 `tools/`의 Temurin 21.0.13+9를 사용할 수 있고, 다른 JDK는 `JAVA_HOME`으로 지정합니다. 다른 운영체제에서 JAR 실행은 가능하도록 작성했지만 실제 검증은 이 Mac에서 수행했습니다.

- **S01 프롤로그**: m 세 글자를 눌러 듣고 슬라이더로 높이→음높이, 너비→길이를 바꿉니다. 세 음 이어 듣기와 도레미파솔라시도 건반, 악기 이미지가 같은 화면에 있습니다. 편집기도 온음계가 기본이며 5음계는 선택할 수 있습니다.

- **S08/S09 공동**: 요일 버튼 또는 S08 표 머리글로 그날 모든 참여자의 합주를 바로 듣습니다. 날짜 칸은 친구 기록을 확인하는 동작입니다. 참여자별 한 주 재생·개별 음 감상·실시간 음소거·음량과 기존 반복/정지/위치 조절을 유지합니다.
- **S14 소리 일기장**: 날짜별 소리 그림·메모·작성자·악기를 모아 봅니다. 검색·기간·작성자·메모 유무·정렬 필터, 선택 기록 듣기/열기, 필터 결과 메모 TXT 내보내기를 제공합니다.
- 최소 창에서 통합 상세는 세로 스크롤로 소리·속성 영역을 보존합니다. 4종 악기/3종 아바타 PNG는 로컬 ImageIcon으로 표시합니다.
- [14화면·5대화상자 컴포넌트/이벤트 표](docs/components.md), [실행 캡처 ZIP](docs/presentation-captures.zip), [사용자 행동→이벤트→피드백과 UX 검토](docs/UX-REVIEW.md)를 제공합니다. 컴포넌트와 배치/모델/그리기 API를 구분합니다.

## 일기 중심 화면과 소리 덩어리

2.1에서는 기존 제안서의 의미 있는 소리 덩어리를 복원했습니다. **꼬리 길이 = 음 길이, 몸통 두께 = 세기, 위아래 = 높낮이**, 가로 위치는 시작 시각입니다. 균일한 원통/캡슐이 아닙니다. 선택은 주황 윤곽과 꼬리 손잡이, 재생 중은 주황 채움, 읽기 전용은 회색으로 구분합니다. 꼬리 끝을 드래그하면 음 길이가 바뀝니다.

연주 설정·곡 관리·내보내기는 관련 메뉴로 묶고, 편집 화면에서는 건반·덩어리·메모·하루 저장에 집중합니다. 보관함·주간 날짜에도 같은 덩어리의 썸네일이 보입니다. 상세 기준은 [디자인 가이드](docs/DESIGN.md)에 있습니다.

## 실제 앱처럼 사용하는 흐름

1. **샘플 바로 듣기 → 곡 선택 → 주간 재생**으로 한 주를 들어봅니다.
2. 각 요일의 ▶는 이어 듣기입니다. 아래 **오늘 편집**은 S06, **기록 열기**는 과거 S07 감상, 미래는 잠금입니다. 오늘도 별도 ‘저장본 감상’으로 읽기 전용 확인이 가능합니다.
3. S06의 건반을 클릭하고 `A S D F G H J K`로 연주합니다. 샘플이 이미 4박을 채웠다면 **다시 연주**로 비운 뒤 입력하거나 기존 음을 편집하세요.
4. 소리 덩어리를 드래그하거나 선택 후 방향키로 이동하고, 오른쪽에서 길이·높낮이·세기를 조절합니다. **Delete/Backspace**로 선택 음을 지웁니다. 오른쪽 ‘표현’ 메뉴에는 쉼·짧게 끊기·점점 세게가 있습니다.
5. **편집 전 듣기 → 들어보기**로 차이를 비교합니다. ‘편집 전’은 첫 시각 편집 직전 음의 복사본이며 악기·BPM은 현재 값을 사용합니다.
6. 메모 → **하루 저장 → D03 확인**. 주간이 저장소에서 다시 읽히고 재실행해도 복원됩니다.

건반·재생·저장 버튼은 기본 창에서 항상 보입니다. 선택한 덩어리의 속성만 오른쪽에 나타나고 추가 표현은 메뉴로 엽니다. 메뉴와 저장 상태, 선택 음의 높이·길이·세기, 메모 글자 수가 표시됩니다.

| 조작 | 단축키 |
|---|---|
| 저장 | Cmd/Ctrl+S |
| 실행 취소 / 다시 실행 | Cmd/Ctrl+Z / Shift+Cmd/Ctrl+Z |
| 새 곡 / 보관함 / 설정 | Cmd/Ctrl+N / O / 쉼표 |
| 건반에서 미리 듣기·정지 | Space |
| 모든 소리 정지 | Escape |
| 도움말 | F1 |

실행 취소/다시 실행에는 음·메모·악기·BPM·입력 위치가 포함됩니다. 한 번의 음 드래그/슬라이더 조작은 한 단계로 묶입니다. 키보드 단축키의 Cmd/Ctrl 조합은 건반 소리를 내지 않습니다.

## 입력·재생·합주

- 단계 입력은 시간 제한 없이 1박씩 입력합니다. ‘쉼 1박’은 다음 입력 위치를 옮깁니다.
- 실시간 입력은 선택한 1~8박 카운트인 뒤 4박 동안 녹음합니다. 설정에서 메트로놈 소리를 켤 수 있습니다. `System.nanoTime()`으로 캡처하고 1/4박에 맞추며 마디 끝에서 자릅니다.
- 4/4, PPQ 480, 1920tick 한 마디, 최소 120tick. 음높이 MIDI 48~84, 음 겹침 허용, 최대 128개 음, 메모 20 코드포인트.
- **재생 막대**: 재생·일시정지·계속 재생·정지·반복·위치 이동. S05/S06/S07/S09에서 동일한 조작을 사용합니다.
- **S09 합주**: 날짜 또는 해당 주 전체 7마디 선택. ‘내 소리만 / 친구 소리만 / 모두 선택’과 파트별 체크·음량으로 비교합니다. 파트 음소거/음량 변경은 재생 중 MIDI 채널에 즉시 반영합니다.
- 공동곡은 공통 BPM으로 재생·편집합니다. 주간 재생도 곡 BPM 하나를 사용합니다. 날짜별 개인 BPM 변화는 개별 S07 감상에서 적용됩니다.
- 빈 날짜/파트는 쉼입니다. 정지·화면 이동·창 포커스 상실 시 음을 종료하며, 반복 keyPressed는 중복음을 만들지 않습니다.

## 곡 관리·악보·파일

- **S10**: 곡 이름·BPM·기본 악기 변경, 참여자·권한 목록. 소유자만 변경 가능하고 저장 전 취소는 데이터에 영향을 주지 않습니다. 오래된 설정으로 덮어쓰는 충돌도 거부합니다.
- **D02**: 공동곡 소유자가 발급한 코드로 같은 저장소의 계정을 초대합니다. 코드 복사, 7일 만료, 무효/만료/중복 참여 구분. 시연의 시계는 고정이므로 시연에서 시간이 자연히 흐르지는 않습니다.
- 참여자는 공동곡에서 탈퇴할 수 있습니다. 과거 기여 기록은 남고 접근 권한만 사라집니다. 소유자 탈퇴·소유권 이전·곡 삭제는 지원하지 않습니다. 합주는 최대 15파트입니다.
- **S11**: 내 주간 NoteEvent를 시간 비례 오선보로 표시, 75~150% 확대, 페이지 분할 인쇄. macOS 인쇄창의 PDF 저장도 사용할 수 있습니다.
- **악보 범위**: 음이름·음높이·시작 위치·길이 숫자/주황선·쉼 시간을 표시합니다. 전문 조판 수준의 성부 분리·음표 충돌 회피·연음/붙임줄·기보 철자 선택은 하지 않습니다. 조밀한 화음은 표기가 겹칠 수 있습니다.
- **MIDI 내보내기**: S06의 ‘더 보기’, S07/S09/S11에서 현재 음, 한 주 또는 선택한 합주를 `.mid`로 저장합니다. BPM·4/4 박자·악기·파트 음량을 포함하며 전체 청취 음량은 파일에 굽지 않습니다. 원본 기록은 바뀌지 않습니다.

## 날짜와 데이터 보호

일반 모드는 기기 시계의 **Asia/Seoul 오늘**, 시연 모드는 명시한 고정 날짜입니다. 서버 날짜라고 주장하지 않습니다.

- 일반: `~/.mmm/local/mmm.properties`
- 시연: `~/.mmm/demo-2026-11-01/mmm.properties`
- 위치 변경: `./run.command --data=/원하는/폴더` 또는 시연 옵션 `--demo-date=YYYY-MM-DD`.
- 파일 잠금·전체 형식 검사·버전 확인·임시 파일 flush·원자 교체로 저장합니다. 쓰기 전 정상 파일은 `mmm.properties.bak`에 이전 상태로 백업합니다. 최초 새 파일에는 이전 백업이 없습니다.
- 손상 파일을 자동 초기화하거나 덮어쓰지 않습니다. 앱을 모두 닫고 별도 원본 사본을 보관한 뒤 정상 백업으로 복원하거나 새 `--data` 위치를 선택하세요. 자동 복구 UI는 없습니다.
- D04는 저장하고 이동 / 버리고 이동 / 계속 편집. 닫기·취소는 편집 유지입니다.
- D05 저장 실패 시 초안 유지 후 재시도. 버전 충돌이나 자정 경계에서 이전 날짜 저장을 강제로 허용하지 않습니다. 충돌 초안 병합과 영구 초안 자동저장은 지원하지 않습니다.
- 계정 비밀번호는 PBKDF2 해시로 저장하지만 **로컬 데모 인증**입니다. 실제 서비스 비밀번호를 사용하지 마세요.
- 저장소 형식이 확장됐으므로 이전 버전 창은 닫고 새 앱을 사용하세요. 기존 데이터는 새 앱에서 읽어 유지합니다.

## 구현 범위와 구조

S01~S14와 D01~D05를 구현했습니다. S14 소리 일기장을 추가했습니다. S10·S11도 로컬 구현이 추가됐습니다. 화면 ID는 내부 식별자로 유지하고 일반 화면 제목에는 노출하지 않습니다. **Spring Boot·PostgreSQL·HTTP 인증·원격 협업·서버 권한/날짜 검증은 미구현**입니다. 점수·랭킹·업적은 계획의 우선 범위가 아니므로 추가하지 않았습니다.

- `Model`: 그래픽·소리·저장의 공통 immutable NoteEvent.
- `MusicService`: 로그인·권한·날짜·곡 관리. `Repository` 계약 / `LocalRepository` 파일 어댑터로 분리.
- `MMM`: 단일 JFrame/CardLayout, 화면·대화상자·SwingWorker.
- `EditorPanel` / `Piano` / `NoteCanvas`: 입력·UndoManager·편집·Graphics2D.
- `MidiEngine` / `Transport`: MIDI, 일시정지·반복·위치 이동·내보내기.
- `ProloguePanel` / `PersonalWeekPanel` / `SharedWeekPanel` / `EnsemblePanel`: 체험·요일 재생·공동 기록·합주.
- `RecordInspector` / `JournalPanel`: 통합 감상과 소리 일기장·검색·메모 내보내기.
- `ScorePanel`: 동일 모델의 악보 렌더링·Printable 페이지 분할.

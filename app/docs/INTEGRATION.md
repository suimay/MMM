- 구형 독립 미리보기 JAR는 새 통합 이력에 넣지 않았다. 소스 브랜치에는 남아 있다.

## 구조와 실행

공통 Model/Api/WireJson/PasswordCodec은 shared/src/main/java/mmm에 둔다.
app와 server는 mmm-shared를 의존하며 shared가 app 소스 폴더를 참조하지 않는다.
독립 Mac·Windows 빌드와 Windows 개발 미리보기는 공통 소스도 함께 컴파일한다.

mvn verify는 ClientRegressionChecks를 별도 Java 프로세스로 실제 실행하고 서버 API/DB 검사를 수행한다.
Maven의 기존 main 기반 테스트에 표시되는 0건과 별도로 실행되는 회귀 검사이며, 실패 시 빌드도 실패한다.
GitHub Actions는 같은 명령을 사용한다.
원격 Swing 시나리오는 -Dmmm.gui.tests=true를 추가한다.
전체 클라이언트 GUI는 app/test-gui.sh 또는 app/build.ps1 -GuiTests로 실행한다.

Mac 패키지는 app/package-mac.sh로 일반 모드 2.6.0을 만든다.
고정 날짜 시연은 app/demo.command로 분리한다.
기존 사용자 로컬 저장소는 통합 검증에 사용하지 않았다.

## 검증

Java 21 독립 빌드에서 클라이언트 회귀 검사 629개를 통과했다.
실제 Mac Swing 검사 242개를 통과했다(기존 218 + 화음 통합 24).
화음 GUI 검사는 쉼·크레센도·스타카토 보존, 겹침 거부, 드럼 차단, Undo/Redo와 파일 재로드를 포함한다.
서버에는 화음·쉼·표현을 저장하고 다른 사용자가 HTTP로 같은 기록을 받는 시나리오를 추가했다.

Windows 스크립트는 공통 소스 경로를 갱신했으며 이번 Mac에서 실제 Windows 실행은 하지 않았다.
서로 다른 물리 기기·운영 TLS·백업 복구·음색의 청취 품질은 별도 확인 대상이다.

# 화음·감정 태그 선정 기준

이 문서는 카탈로그에 어떤 관계를 넣고, 그 관계를 어떻게 해석할지 정합니다. 자료 구조나 화면을 수정할 때에도 이 구분을 유지합니다.

## 1. 태그가 뜻하는 것

음음음의 태그는 **소리에서 지각되는 감정적 인상(perceived emotion)**입니다. 사용자가 실제로 느낀 감정(felt emotion)이나 현재 기분과 동일하게 취급하지 않습니다. 이 구분과 질문 방식의 중요성은 [Merrill 외, 2020](https://doi.org/10.1371/journal.pone.0237641)을 참고했습니다.

| 구분 | 예시 | 이번 기능에서의 처리 |
|---|---|---|
| 음악의 인상 | “이 화음이 쓸쓸하게 들린다.” | 후보 탐색을 위한 태그 |
| 청취자의 실제 느낌 | “이 소리를 듣고 위로받았다.” | 태그 점수에서 추론하지 않음 |
| 사용자 상태 | “사용자가 지금 슬프다.” | 판정·저장하지 않음 |

태그는 서로 배타적인 감정 분류가 아닙니다. 한 화음에 여러 인상이 공존할 수 있습니다. `긍정적인`은 원문의 **valence(정서가)**를 나타내며, `기쁨`이나 `선호도`와 같은 값으로 합치지 않습니다.

## 2. 현재 채택한 직접 후보 관계 9개

아래 값은 [Lahdelma & Eerola, *Single chords convey distinct emotional qualities to both naïve and expert listeners*](https://doi.org/10.1177/0305735614552006)에 보고된 **화음 유형별 평균과 표준편차**입니다. **모두 1–5 척도이며 두 음색과 해당 화음에 적용한 전위 조건을 합친 요약값**입니다. 감·증화음에는 기본위치만 사용했으므로 모든 행에 여러 전위가 포함된 것은 아닙니다.

| 화음 유형 | 앱의 C근음 예시 | 사용자 태그 | 원문 측정 차원 | 평균 | SD |
|---|---|---|---|---:|---:|
| Major triad | C | 기쁨 | Happiness/Joy | 3.36 | 0.81 |
| Major triad | C | 긍정적인 | Valence | 4.04 | 0.61 |
| Minor triad | Cm | 슬픔 | Melancholy/Sadness | 3.44 | 0.77 |
| Minor triad | Cm | 그리움 | Nostalgia/Longing | 2.90 | 0.77 |
| Major seventh | Cmaj7 | 그리움 | Nostalgia/Longing | 2.89 | 0.82 |
| Minor seventh | Cm7 | 그리움 | Nostalgia/Longing | 2.84 | 0.77 |
| Augmented triad | Caug | 긴장감 | Tension | 3.99 | 0.80 |
| Diminished triad | Cdim | 긴장감 | Tension | 3.79 | 0.78 |
| Dominant seventh | C7 | 긴장감 | Tension | 3.46 | 0.61 |

### 이 표를 읽는 방법

- 평균은 연구 참가자들의 평정 요약입니다. SD는 평정의 퍼짐을 나타내며 신뢰도, 확률, 표준오차가 아닙니다.
- 원문에서 해당 화음의 연구 조건에 걸쳐 집계한 값이므로 **현재 C4 기본위치 피아노 샘플의 측정값이 아닙니다.**
- 2.90과 2.89 같은 차이로 후보 순위를 정하지 않습니다. 이 표 자체는 특정 두 화음의 차이가 유의하다는 검정 결과를 제공하지 않습니다.
- 평균을 5로 나누어 “그리움 확률”로 표시하지 않습니다. 1–5 척도는 감정 발생 확률 척도가 아닙니다.
- `그리움`은 원문의 `Nostalgia/Longing`을 간단하게 표현한 UI 번역입니다. 향수·그리움과 한국어의 모든 유사 표현이 같은 개념이라는 뜻은 아닙니다.
- `긍정적인`은 쾌·불쾌 방향의 정서가를 나타내는 명칭입니다. “더 좋아하는 화음”을 뽑는 선호도 순위로 쓰지 않습니다.

이 카탈로그에는 직접 연결 9개만 채택했습니다. 위 연구에서 다룬 모든 화음·측정 차원의 전체 표를 재현하거나, 감정 전체를 망라한 분류 체계를 제공하는 것은 아닙니다.

## 3. 채택 규칙

후보 관계를 추가하려면 다음 조건을 모두 확인합니다.

1. **근거가 추적 가능해야 합니다.** 저자·제목·연도·DOI와 해당 결과의 위치를 확인할 수 있어야 합니다.
2. **실험 단위가 맞아야 합니다.** 단일 화음의 결과는 화음 후보에, 진행이나 곡의 결과는 해당 문맥의 설명에 사용합니다. 곡 전체의 결과를 한 코드의 고정값으로 옮기지 않습니다.
3. **측정한 개념을 유지합니다.** 긴장감이 높다는 결과를 공포가 발생한다는 주장으로 바꾸지 않습니다. 긍정 정서가·기쁨·선호도도 구분합니다.
4. **수치의 의미를 보존합니다.** 원문값과 앱에서 정한 값, 재계산한 값, 후속 조사값을 구분합니다. 원문에 없는 표본·효과크기·확률을 채우지 않습니다.
5. **조건 차이를 공개합니다.** 음색·음역·전위·지속시간·문화적 배경 등 적용에 필요한 한계를 근거 항목에 함께 둡니다.
6. **사용자 청취 검증 상태를 표시합니다.** 문헌에 근거가 있다는 것과 실제 앱 샘플이 검증됐다는 것을 별도 상태로 취급합니다.

현재 연결은 문헌에 근거한 **초기 탐색 후보**입니다. 평균이 어떤 고정 임계값을 넘으면 자동으로 채택하는 규칙은 사용하지 않았습니다. 새로운 임계값을 도입하려면 근거와 용도를 문서화하고 사용자 평가 전에 정해야 합니다.

## 4. 보류한 표현 5개

아래 표현은 현재 카탈로그의 사용 가능한 태그 목록에 넣지 않습니다. 이는 해당 감정이 음악에서 표현될 수 없다는 결론이 아니라, **현재 등록한 직접 후보 관계로 그 표현을 충분히 설명하지 않았다는 상태**입니다.

| 보류 개념 | 검토할 한국어 표현 | 보류 이유와 다음 확인 |
|---|---|---|
| Tenderness | 다정함·부드러움 | 원문의 측정 차원과 UI 단어의 범위를 확인하고 후보별 근거를 별도로 정리 |
| Dreaminess | 몽환적임 | 그리움·불협화·낮은 활력에서 자동으로 변환하지 말고 직접 평가 필요 |
| Romance | 로맨틱함 | 그리움·긍정 정서가와 구분되는 인상인지 확인 필요 |
| Hopefulness | 희망적임 | 장화음·기쁨과 같은 의미로 간주하지 말고 상황·진행을 포함해 검토 |
| Fear | 공포 | 긴장감 또는 부정 정서가만으로 공포를 확정할 수 없음 |

관련 표현이 어떤 논문에 등장한다는 사실만으로 현재 샘플과의 관계가 검증되는 것은 아닙니다. 보류 태그를 활성화하려면 출처·측정값 또는 실제 앱 샘플의 청취 결과를 갖춘 새로운 근거 항목이 필요합니다.

## 5. 화음 샘플의 구성

첫 버전은 음역·근음 차이를 줄이기 위해 모든 후보를 C4 기본위치의 좁은 배치로 맞춥니다. 아래 음높이는 미리 듣기와 삽입의 구성음 정의이며 감정 점수가 아닙니다.

| 화음 | 구성음 | MIDI 음높이 |
|---|---|---|
| C | C4–E4–G4 | 60, 64, 67 |
| Cm | C4–E♭4–G4 | 60, 63, 67 |
| Cmaj7 | C4–E4–G4–B4 | 60, 64, 67, 71 |
| Cm7 | C4–E♭4–G4–B♭4 | 60, 63, 67, 70 |
| Caug | C4–E4–G♯4 | 60, 64, 68 |
| Cdim | C4–E♭4–G♭4 | 60, 63, 66 |
| C7 | C4–E4–G4–B♭4 | 60, 64, 67, 70 |

미리 듣기는 GM 프로그램 0, 입력 velocity 72, 60 BPM, 1920 tick(4박·4초)을 사용합니다. 모든 음은 동시에 시작합니다. 실제 출력에는 앱의 전체 음량 설정이 적용되고 음색은 기기의 MIDI 신시사이저·사운드뱅크에 영향을 받습니다. 물리적인 음압을 정규화한 조건은 아닙니다. 이 값은 비교를 위한 제품 설정이며 논문 실험 설정에서 그대로 추출한 값이 아닙니다.

편집기에 삽입한 뒤에는 현재 악기·BPM과 사용자가 선택한 시작 박·길이가 적용됩니다. 앞뒤에 놓인 음과 화성 문맥도 달라집니다. 따라서 원문 평정이 편집 결과 전체에 그대로 유지된다고 주장하지 않습니다.

| 근거 | 이번 기준에 반영한 점 |

각 연구의 정확한 실험 범위와 사용하지 않는 해석은 [SOURCES.md](SOURCES.md)에 있습니다. 위 논문들을 모았다는 이유로 현재 9개 관계가 모든 문화·모든 편곡에서 재현된다고 주장하지 않습니다.

## 7. 카탈로그 변경 시 남길 기록

태그를 추가·삭제하거나 연결을 바꿀 때는 **무엇을 바꿨는지, 어떤 근거가 추가됐는지, 실제 샘플 조건이 달라졌는지, 사용자 평가가 있는지**를 PR에 기록합니다. 논문 서지 정정과 감정 연결 변경은 구분해서 설명합니다.

자료를 읽을 수 없거나 관계가 잘못된 경우에는 누락된 값을 추측하여 추천을 계속하지 않습니다. 실패를 드러내고 카탈로그를 고친 뒤 다시 검증합니다. 구체적인 개발 검수 항목은 [VALIDATION.md](VALIDATION.md)를 따릅니다.

현재 스키마 1.0.0은 사용 가능한 태그에 측정 차원이 맞는 수치 근거와 직접 연결을 요구하며, 7종의 알려진 화음과 독립·기본위치·좁은 배치의 미검증 샘플만 지원합니다. 전위·진행·새 측정 차원·자체 검증 결과를 추가하려면 자료뿐 아니라 로더·검증 규칙·테스트와 스키마 버전을 함께 바꿉니다. 조사 결과가 생겼다고 기존 논문 평균이나 `not_validated` 문자열만 덮어쓰지 않습니다.

# M2 구현·검증 · 2026-11-16

이 문서는 2.5 기본 구현의 검증 이력이다. 후속 2.5.1의 활동 로그와 서버 시나리오 19개 검증은 [활동 로그 기록](ACTIVITY-LOGGING.md)을 따른다.

GitHub 7e0702b + 이번 2.4 로컬 구현에서 2.5 원격 모드를 추가했다. 기존 명세서·발표 자료·2.4 배포본은 보존했다.

Windows / Microsoft OpenJDK 21.0.13.0.2 / Maven 3.9.9 / Spring Boot 3.5.16 / 실제 PostgreSQL 14.22에서 검사했다. 클라이언트와 서버는 Java 21 클래스 형식으로 빌드했다.

| 검사 | 결과 |
|---|---|
| 클라이언트 모델·파일·권한·MIDI·그리기·합주·표현 | 154개 통과 |
| HTTP JSON·잘못된 응답·DTO/비밀번호 경계 | 28개 통과 |
| 기존 실제 Swing 흐름 | 73개 통과 |
| v0.2 표현·저장·최소 창·실시간 입력 Swing | 54개 통과 |
| 서버 HTTP(S)/DB 통합 시나리오 | 16개 통과, 실패/오류/생략 0 |

클라이언트 기본 182 + Swing 127 = 309개다. 서버는 여러 assertion으로 구성한 JUnit 시나리오 16개로 별도 집계한다. main 기반 검사는 Maven Surefire의 0개 표시와 별도로 build-m2.ps1에서 실행한다.

## 서버 시나리오

1. 가입·중복·로그인 실패·공개 DTO·해시 저장·로그아웃 토큰 폐기·비인증/없는 경로.
2. A 저장 → B 조회, 같은 음·쉼·표현·메모·버전, 실제 MIDI NOTE_OFF 60tick, 재로그인 후 조회.
3. 비참여/개인 곡 조회, 참여자의 설정·초대 위조, 임의 작성자 필드, 과거/미래 저장 거부.
4. 같은 requestId는 최초 결과, 후속 저장 후에도 최초 버전 응답, 변경 본문 재사용 거부.
5. 같은 버전 동시 저장은 하나만 성공. 동일 요청 동시 제출은 같은 결과와 한 번의 버전 증가.
6. 자식 음/쉼 교체 후 표현 삽입에 실제 DB 트리거 실패 주입 → 메모·자식·버전·요청 모두 롤백.
7. 탈퇴 후 접근 제거·기여 기록 보관·소유자 탈퇴 차단·재초대.
8. 초대 만료 경계와 활성 참여자 15명 제한.
9. 곡 버전 충돌·계정별 설정·원격 어댑터의 인증 해시 조회 금지.
10. 메모·음역·음/쉼 중첩·공동 BPM·스키마·조회 범위·크기, 소수 tick·문자열 숫자·누락 버전·중복 JSON 키 거부, 20 이모지·명시적 쉼만 저장.
11. 세션 만료·실패한 재로그인에도 초안 작성자 유지·자정 후 거부·서버 날짜 갱신.
12. 저장 성공 후 응답을 503으로 대체 → 동일 초안 재시도에서 중복 저장 없음.
13. 시간 초과·외부 HTTP·URL 내 자격 정보 거부.
14. 별도 JVM 두 프로세스의 A 저장·B 조회. 로컬 파일 공유 없이 HTTP/DB로 같은 기록 수신.
15. HTTPS 미신뢰 인증서는 실패, 테스트 JVM 신뢰 등록 후 가입·로그인·저장·조회 성공. 제품에 TLS 검증 해제 없음.
16. 실제 원격 Swing 로그인·편집·확인·저장·다른 사용자 조회, 충돌 초안 보존, 세션 만료 재로그인 후 같은 초안 유지. 자동 재저장 없음.

## 배포 실행 검사

개발 서버 JAR로 실제 PostgreSQL 초기화 → 가입 → 표현/쉼 기록 저장 → stop으로 정상 종료 → 같은 DB 경로 재시작 → 계정·음·쉼·메모 복원을 확인했다. 처음은 JDK 21, 재시작은 이 컴퓨터의 Oracle Java 26.0.2.1로 검사했다. 개발 서버는 루프백만 열며 일반 배포 서버 JAR는 별도다.

Windows ZIP을 실제로 풀어 start-server.cmd와 remote.cmd로 서버·클라이언트를 실행하고, 내부 JAR 체크섬과 Java 21 클래스 형식을 확인했다. 일반 서버 실행 JAR도 별도 프로세스로 시작해 외부 DB 환경 변수 연결·인증·저장을 검사하고, 같은 DB의 다른 서버 인스턴스에서 동일 기록과 세션을 조회했다.

## 검증 한계

같은 Windows 호스트의 별도 JVM과 실제 네트워크 소켓을 검사했다. 물리적으로 다른 두 기기, 외부 네트워크·방화벽·DNS·운영 인증서·DB 운영 환경은 확인하지 않았다. 로컬 HTTPS 프록시의 인증서 신뢰와 API 전송을 검사했으며 운영 Boot TLS 배포는 별도 확인 대상이다.

Docker 데몬이 꺼져 있어 Compose/PostgreSQL 17은 실행하지 않았다. macOS/Linux 패키지, 실물 인쇄·OS PDF 창, 청음 품질·잔음 평가는 수치에 포함하지 않는다. 운영 백업/복구·고가용성 제공을 주장하지 않는다.
